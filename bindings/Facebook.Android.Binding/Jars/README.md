# Facebook SDK file

**Included:** `facebook-core-18.0.3.aar` is in this folder, so you can build immediately.

## Or download it yourself

- **SDK:** `com.facebook.android:facebook-core:18.0.3`
- **Official source:** Maven Central

```powershell
curl.exe -L -o facebook-core-18.0.3.aar "https://repo1.maven.org/maven2/com/facebook/android/facebook-core/18.0.3/facebook-core-18.0.3.aar"
```

Save it as `Jars/facebook-core-18.0.3.aar`.
